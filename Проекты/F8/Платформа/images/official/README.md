# Official images

Канонический публичный визуальный слой релиза **F8.0 — «Платформа»**.

## Структура

- `common/` — шесть общих сюжетных иллюстраций, не зависящих от языка.
- `ru/` — опубликованные русские заставки глав, буквицы и обложка; структура сохранена ради совместимости с уже выпущенным русским контуром.
- `en/`, `uk/`, `es/`, `fr/`, `de/`, `it/`, `ja/`, `zh/` — локализованный визуальный слой переводов.
  - `chapter-panels/` — четыре заставки глав.
  - `dropcaps/` — четыре буквицы соответствующей редакции.

## Статус файлов переводов

Локализованные заставки и буквицы восстановлены из **встроенных растровых ресурсов A5 PUB RC1**, а не сняты скриншотами со страниц. Для GitHub опубликованы облегчённые web-копии с сохранением канонического изображения и имени файла.

Эти файлы являются официальными **публичными web-артефактами**. Они не заменяют производственные print-мастера высокого разрешения, если такие мастера сохраняются отдельно в рабочем архиве.

## Языки

RU · EN · UK (українська) · ES · FR · DE · IT · JA · ZH

Сюда помещаются только материалы, допустимые для публичного релиза. Рабочие исходники, промежуточные варианты и приватные QA-материалы остаются вне публичного репозитория.
