# F8.0 — Платформа

Публичный каталог произведения **«Платформа»** из цикла F8.

## Текущий статус

Русское издание доведено до **F8.0 · RU-PUB RC3 · 57 I.E. · 25 октября 2026**.

Версии разведены по назначению:
- **F8.0** — идентификатор произведения;
- **RU-TEXT 1.0.2** — редакция русского литературного текста;
- **LAYOUT 2.7** — история русской вёрстки;
- **RU-PUB RC3** — текущий издательский релиз-кандидат;
- **RU-PUB 1.0** будет присвоен только после финального авторского и печатного утверждения.

- формат: A5;
- внутренний блок: 47 страниц;
- пагинация считается с первой внутренней страницы;
- лицевая обложка входит в мастер-пакет и единый просмотровый мастер, но остаётся отдельным производственным файлом для типографии;
- визуальный пролог `fig01_platforma_nad_okeanom.jpg` остаётся перед оглавлением;
- главы открываются на правых полосах; оглавление: 6 / 13 / 23 / 37;
- все панели, буквицы и сюжетные изображения имеют видимые малые служебные подписи с полным именем файла и расширением;
- визуальный ритм описан в [image-map.md](./image-map.md);
- канонический русский текст для совместного чтения с ИИ: [text/platforma_ru_for_ai_v1.0.md](./text/platforma_ru_for_ai_v1.0.md).

## Публичные переводы

Опубликован полный пакет литературных **TEXT 1.0**: EN / UK / ES / FR / DE / IT / JA / ZH. Все переводы выполнены непосредственно от RU-TEXT 1.0.2 и доступны в [translations/](./translations/).

A5-печатные кандидаты существуют отдельно, но их PDF-релиз заморожен до исправления локализованного обтекания иллюстрации V60 и последующего author/print proof. Публикация текстов не означает утверждения печатных PUB 1.0.

## Публичный / рабочий контур

Этот GitHub-каталог предназначен только для публично допустимых материалов релиза. Рабочие журналы, личные заметки, промежуточные редакции и приватные Google Drive-ссылки сюда не переносятся.

- `text/` — утверждённые публичные тексты;
- `images/official/` — опубликованные канонические изображения;

## ИИ и переводы

Канонический файл для совместного чтения с ИИ остаётся русским оригиналом. Отдельный «AI-перевод» для каждого языка не требуется: переводы создаются прежде всего как человеческие литературные издания; ИИ при необходимости может работать и с оригиналом, и с опубликованной переводной редакцией.
