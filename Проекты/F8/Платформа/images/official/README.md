# Official images

Канонические публичные изображения релиза «Платформы».

- `common/` — изображения, не зависящие от языка.
- `ru/` — русские заставки глав и буквицы.
- Для каждого нового перевода создаётся собственная языковая подпапка с локализованными заставками глав и буквицами.

Сюда помещаются только материалы, утверждённые для публичного релиза.
