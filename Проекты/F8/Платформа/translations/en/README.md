Read it here:

- [platform_en_text_v1.0.md](./platform_en_text_v1.0.md)

## A5 public reading proof

The current A5 layout candidate is also available publicly as a **reading proof**:

- [EN A5 PUB RC1 — public proof](https://www.canva.com/d/ZwKMTjT8xuuzJGf)

This is **not printer-final**. It is being published intentionally before the final print pass so readers can access the designed edition and report layout problems. A known local V60 image/text-flow defect remains in the multilingual A5 branch.

Publication of this proof does not change the status of the locked literary text: **EN-TEXT 1.0** remains the text reference.

Common narrative images `fig01`–`fig06` are shared with the Russian edition unless a language-specific replacement is explicitly approved.
