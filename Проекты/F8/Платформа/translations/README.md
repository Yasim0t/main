# Translations

Языковые редакции «Платформы».

Каждый перевод должен иметь:
- текст перевода;
- собственные локализованные заставки глав;
- собственные буквицы;
- карту изображений;
- отдельную редакторскую проверку относительно утверждённого русского мастера.

Первый планируемый перевод — английский.
